# sfx-library — bring your own whoosh

Ships empty (audio is gitignored) for the same licensing reason as
[`bgm-library/`](../bgm-library/README.md). Drop any short transition sound
you are licensed to use in as `whoosh.mp3` (the path `config.py` reads as
`SFX_TRANSITION_FILE`); without it the SFX step skips cleanly and the build
is unaffected.
